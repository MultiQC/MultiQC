Browser agents (WebMCP)

This report includes WebMCP tools that let a browser AI agent:

  • Read an overview of the report's modules and plots.
  • Read QC data from interactive plots and General Statistics.
  • Navigate to a report section.

Browser status: Checking browser support...

Your browser and AI agent must support WebMCP. Use your browser agent's site tool controls to allow access to this report. The tools work from this HTML file without a MultiQC server or API key.

When you ask an agent to use these tools, it can read the report's QC data. Current sample and column filters and AI sample anonymization apply. Plot values may be scaled or downsampled.
